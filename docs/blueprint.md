# **App Name**: Gift Shop Agadir

## Core Features:

- Luxury Product Catalog: A dynamic showcase of trophies, medals, and personalized gifts with search and multi-criteria filtering.
- Personalization AI Assistant: A tool that uses generative AI to help customers draft perfect engraving messages and personal dedications for their gifts.
- Direct WhatsApp Ordering: Seamless integration allowing users to finalize orders and inquiries directly through WhatsApp from product pages.
- Real-time Inquiry Tracking: Persistent inquiry system using Firestore to save customer requests and track status in real-time.
- Elite Admin Dashboard: Secure dashboard for complete CRUD management of products, orders, categories, and site-wide CMS settings.
- Visual Media Manager: High-performance gallery and media library integrated with Firebase Storage for product and hero assets.
- Location & Directions Suite: Interactive Agadir-specific mapping integration with one-click route directions to the physical store.

## Style Guidelines:

- Primary Color: Vibrant Magenta (#D81E5B) inspired by the brand logo to convey celebration and energy.
- Background Color: Deep Navy Black (#0F172A), a dark and elegant canvas that allows tropical brand colors to pop.
- Accent Color: Sunset Golden Yellow (#FACC15), providing high-contrast highlights for buttons and interactive elements.
- Headlines and Body: 'Poppins', a geometric sans-serif that reflects a modern, friendly, and premium shopping experience.
- Utilize Lucide icons with a rounded, 2px stroke width to match the soft, welcoming design aesthetic of the Agadir storefront.
- Responsive grid layout with high white space (or 'negative space'), featuring card-based product displays and glassmorphism headers.
- Framer Motion transitions including subtle hover scales, staggered entrance reveals for product grids, and smooth fade-in transitions between pages.
